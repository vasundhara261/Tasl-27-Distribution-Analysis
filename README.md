 Distribution Analysis

## Objective
To understand how numerical data is distributed using a histogram.

## Dataset
Iris Dataset

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis
A histogram was created for a numerical variable from the Iris dataset to understand the distribution of values.

## Key Observations
- The histogram shows how frequently values occur within different ranges.
- The center represents where most values are concentrated.
- The spread shows how widely the values are distributed.
- The shape of the distribution helps identify whether the data is symmetric or skewed.

## Conclusion
Distribution analysis helps us understand the pattern and characteristics of numerical data.
